`export let`, no `on:click`). Props with defaults:


- a **bogus `tileUrl`** degrades to an empty map — never a broken page, never an unhandled throw;
- the map is **destroyed on component teardown** (`map.remove()` in the effect cleanup), or the dev
  server will leak maps across navigations.

  DB layer already selects them);
- type the response **inside your own route file**. You do not own `web/src/lib/api/**`, so do not add a
  client module there;
