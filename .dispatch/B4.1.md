## Why this card exists

The shipped template cannot start the project. It still carries `[auth] jwt_secret`, `[federation]`, `[relay]` and
`[discovery] registration_mode` — keys the merged `Config` struct no longer has. Serde ignores unknown fields, so
those are silent; but a reader who copies the template and runs the server hits `[registration]
require_email_verification` defaulting to **true** with no `[email]` section, and the server refuses to start:

    [registration] require_email_verification is true but [email] is not configured:
    set smtp_host and from, or set require_email_verification = false

Net effect: the documented way to start this project does not work. B5 filed it as unowned; it is yours now.
