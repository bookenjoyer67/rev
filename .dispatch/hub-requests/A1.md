(A5.2 also strips `communities_count` / `federation_enabled` from the same struct), so A1 has
not edited it.

## 2. `cargo build --workspace` cannot pass at the close of A1 (scope contradiction, not a defect)

A1's gate asks for a clean `cargo build --workspace`, but A1's file list excludes
`crates/server/src/api/**` and `crates/server/src/db/**`, which is exactly where the community
model is consumed. Deleting `Community` / `Member` / `Visibility::Federated` / `Post.community_id`
(A1.2, required by the card) therefore breaks those files by construction, and repairing them **is**
Wave A3.

Measured after A1: **26 errors, all of them in files A1 does not own.**

| File | Owner | Errors | Cause |
|---|---|---|---|
| `crates/server/src/db/posts.rs` | Agent A, Wave A3 (A3.1) | 14 | `Post.community_id`, `Category::*` enum variants, `Visibility::Federated`, `federated_id`, `origin_node` |
| `crates/server/src/api/communities.rs` | Agent A, Wave A3 (A3.1 deletes the file) | 6 | `Community` / `CreateCommunity` / `Invite` imports, `Visibility::Federated`, `AppState.relay_store`, `crate::relay_ops` |
| `crates/server/src/db/communities.rs` | Agent A, Wave A3 (A3.1 deletes the file) | 4 | same imports, `Visibility::Federated` |
| `crates/server/src/api/node.rs` | Agent B, Wave A5.2 | 1 | `config.relay` — fixed by item 1 above |

Nothing in A1's own write set fails to compile: `cargo build -p komun-core -p komun-wasm` is clean
and `cargo test -p komun-core` is green (20 tests).

Suggested resolution, in preference order:

1. Treat A1's workspace-build gate as **deferred to A3** and re-run it there. A1's real exit
   criteria (`cargo test -p komun-core`, the schema probes, the negative inserts, zero `piggpin`)
   all pass today.
2. Or widen A1 to include `db/posts.rs`, `db/communities.rs`, `api/communities.rs` — but that is
   A3.1 verbatim, so it merges the two cards rather than resolving anything.

Recommendation: option 1. A1 and A3 then commit separately, and the first commit is a tree that
does not build on its own — if that is unacceptable, A1 and A3 should be dispatched and committed
as one unit.
